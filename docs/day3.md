### Migrating VPC CNI to EKS Managed Addon

This component is responsible for assigning IP addresses to pods, enabling communication within the cluster and with external services. It typically runs as a DaemonSet.

**Key Migration Concepts:**
*   The migration process involves moving from a self-managed setup to an AWS EKS managed addon using `aws eks create-addon`.
*   Understanding configuration conflicts (e.g., PRESERVE vs OVERWRITE) is crucial, as improper handling can lead to failed migrations.
*   Security considerations often involve verifying the OIDC provider and setting up IRSA for proper role-based access control.

Monitoring the migration pods during this process is essential.

### Kubermatic SecureGuard

Open source secrets management platform built on OpenBao and External Secrets Operator.

The problem is kubernetes secrets are base64 encoded. Anyone having access to cluster can decode with right permissions. If they have access to etcd then they can directly read unecrypted secret.

OpenBao is open source version of HashiCorp Vault.

Three keys that are required

- Static Key: This is auto-unseal key that encrypt's OpenBao's master key. We should store this in password manager. Cluster won't start if this is incorrect.
- Recovery Key: Generated by OpenBao during `bao operator init`. If we loose root token, this can be used to generate a new one.
- Root token: Generated during start up which gives access to API and UI.

This can be used for small scale kubernetes clusters.
